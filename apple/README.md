# 方方詞卡

iPhone／iPad 的台語單詞卡 App。像交友 App 一樣滑卡片：

- **往右滑 = 認識** → 放進「熟悉」
- **往左滑 = 不熟** → 放進「不熟」，可以練習

卡片顯示漢字、皓羅（可切換台羅／白話字）、方音、白／文標示、釋義、例句和發音。詞按照常用程度排列（依教育部辭典例句裡出現的次數）。

## 安裝

需要：

- 一台 Mac，裝好 **Xcode 26 以上**（App Store 免費下載；需要 **macOS Sequoia 15.6 以上**，比較舊的 macOS 裝不了這麼新的 Xcode，也就不能建置這個 App），打開一次，在 **Xcode → Settings → Accounts** 用你的 Apple ID 登入（免費的 Apple ID 就可以）。
- iPhone／iPad：iOS／iPadOS 17 以上；Mac 版：macOS 14 以上。

步驟：

1. 在 GitHub 按 **Code → Download ZIP**，解壓縮到「下載項目」，資料夾會叫 `fangfang-cards-main`。（用 git clone 的話，指令裡的路徑換成你 clone 的資料夾。）
2. 第一次裝到 iPhone／iPad 的話：用傳輸線接上 Mac，手機上按「信任這部電腦」。然後打開 **設定 → 隱私權與安全性 → 開發者模式**，打開，手機會重新開機。（開發者模式的選項要接過 Mac、或在 Xcode 的「Devices and Simulators」看過這支手機之後才會出現。）
3. iPhone 解鎖，接上傳輸線（或跟 Mac 連同一個 Wi-Fi）。
4. 打開 Terminal，執行：

```
bash ~/Downloads/fangfang-cards-main/install.sh
```

5. 第一次在 iPhone／iPad 打開 App 時，如果說「未受信任的開發者」：**設定 → 一般 → VPN 與裝置管理**，點你的 Apple ID，按「信任」。

它會自動建置 App，安裝到所有找得到的 iPhone／iPad，**也會裝一份到 Mac**（「應用程式」資料夾裡的「方方詞卡」）。

- 只裝手機／平板：`install.sh ios`；只裝 Mac：`install.sh mac`
- Apple 晶片（M1 以後）的 Mac：第一次會問你要裝 **iPad 版**（建議）還是 **Mac 版**，之後會記住。想換：`install.sh ipad` 或 `install.sh catalyst`。Intel Mac 一律裝 Mac 版。
- 免費 Apple ID：**7 天後再執行一次同一個指令**就好（資料不會不見）。（用 `install.sh catalyst` 裝的 Mac 版不會過期。）
- **App 裡面沒有內建任何詞典。** 第一次打開 App 選語言的時候，App 會自己下載那個語言的詞典，在 iPhone／iPad／Mac 上整理好（要網路，大概一兩分鐘）；其他語言的在「設定 → 詞典資料」安裝。
- Safari 查詞的延伸功能看不到 App 下載的詞典（要 App Group，用 Sideloadly 裝通常沒有），所以 install.sh 會在你的 Mac 上建立詞典資料（放在 `~/FangfangCards/data`，不會放進 App），只把查詞要的詞放進延伸功能。第一次要幾分鐘。不要 Safari 查詞的話，在指令最後加上 `nosafari`（例如 `install.sh ipa nosafari`）。
- App 的 ID 會用你自己的開發者團隊產生（`com.fangfangcards.你的團隊ID`），因為每個 ID 只能有一個人用。想用別的 ID：`FANGFANG_ID=com.你的名字.fangfang bash …/install.sh`。
- 建置失敗的話，Terminal 會列出錯誤訊息，完整紀錄在 `~/Library/Logs/fangfangcards-build.log`。

專案會放在家目錄的 `FangfangCards` 資料夾。想用 Xcode 打開也可以：雙擊 `~/FangfangCards/FangfangCards.xcodeproj`，上方選你的 iPhone 或「My Mac」，按 ▶（第一次要在專案設定的 Signing & Capabilities 選你的 Team，並把 Build Settings 裡的 `FF_ID` 改成你自己的，例如 `com.你的名字.fangfang`）。

### 用 Sideloadly 安裝（Mac 太舊、不能裝 Xcode 26 的時候）

1. 有新 Mac 的人執行 `install.sh ipa`，桌面會出現 `FangfangCards.ipa`，把這個檔案傳給對方。
2. 對方在自己的電腦（Mac 10.12 以上，或 Windows）安裝免費的 [Sideloadly](https://sideloadly.io)。
3. iPhone 用傳輸線接上電腦，解鎖，按「信任這部電腦」。
4. 打開 Sideloadly，把 `FangfangCards.ipa` 拖進去，填自己的 Apple ID（要曾經在 iPhone 上登入過的），按 **Start**，輸入密碼（有雙重認證的話輸入驗證碼）。
5. 第一次：iPhone 打開 **設定 → 隱私權與安全性 → 開發者模式**，打開並重新開機；再到 **設定 → 一般 → VPN 與裝置管理**，信任自己的 Apple ID。
6. 免費 Apple ID：7 天後用 Sideloadly 再裝一次同一個檔案（不要先刪掉 App，資料才會留著）。

用這個方法裝的話，「分類詞卡」小工具可能沒辦法用（App 本身都正常）。

### Mac 版

Apple 晶片（M1 以後）的 Mac 有兩種可以選（安裝時會問）：

- **iPad 版（建議）**：就是 iPad App 本身，跟 iPad 上的完全一樣，比較順，聲調光暈也一樣漂亮。視窗就像一台大 iPad；鍵盤 **←**（不熟）、**→**（認識）一樣可以用，文字大小也可以調。免費 Apple ID 的話 7 天後要重新執行安裝指令。第一次打開時 Mac 可能會要你到「系統設定 → 隱私權與安全性」按「強制打開」。
- **Mac 版**（Mac Catalyst）：分頁變成側邊欄，「轉換」在寬的視窗分成左右兩欄，有選單列。不會過期。滑鼠移過去放大字比較不順，所以聲調光暈用比較簡單的畫法。

Intel Mac 不能執行 iPad App，一律裝 Mac 版。

**文字大小**（iPad、Mac）：設定 → 顯示 → 文字大小（100%–310%），或接鍵盤用 **⌘+**／**⌘−**／**⌘0**。iPad 預設 100%（跟原本一樣），Mac 版預設 135%。iPhone 跟著系統的文字大小。

### 詞典資料

App 裡面和 GitHub 上都**沒有任何詞典資料**。詞典的授權不允許散布改過的版本，所以 App 從原本發布的地方下載檔案，在你的裝置上自己整理：第一次打開 App 選語言的時候會自動安裝那個語言的詞典，其他的在「設定 → 詞典資料」。

只有 Safari 查詞要在 Mac 上建立資料（`install.sh` 會自動做，加 `nosafari` 就跳過）。也可以自己執行：

```
bash build-data.sh                       # 台語（自動下載 kautian.ods）
bash build-data.sh zh                    # 華語
bash build-data.sh yue                   # 粵語（含維基詞典）
```

需要：Python 3（Mac 上裝了 Xcode 就有）。做出來的檔案不會放進 App（install.sh 會把它們移到 `~/FangfangCards/data`）。

## 功能

| 分頁 | 做什麼 |
|---|---|
| **新詞** | 從最常用的詞開始滑。↺ 可以復原上一張。 |
| **不熟** | 往左滑的詞。按「開始練習」做題目。列表往右滑 → 直接移到熟悉；往左滑 → 移回新詞。 |
| **熟悉** | 往右滑的詞。「卡片複習」可以再滑一次：往左滑的詞會回到「不熟」。 |
| **轉換** | 方方轉換器（App 本身的畫面）：漢字 ⇄ 皓羅 ⇄ 方音，也讀台羅／白話字。點輸出的詞可以換讀音（會記住）、看辭典解釋、收藏、加到「不熟」。也可以把整段的新詞一次加到「不熟」或收藏。 |
| **詞典** | **查詞**：查華語詞、各地講法；用 * 和 ? 找台語詞（人* = 人開頭、*仔 = 仔結尾、*水* = 水在中間、?仔 = 兩個字仔結尾）。**分類**：教育部辭典的 199 個分類，每個分類的詞照常用程度排，可以一次把新詞加到「不熟」。**收藏**：收藏的詞，可以匯出 CSV。**自訂**：自己加的詞（漢字＋讀音，讀音用皓羅、台羅、白話字或方音都可以），在「轉換」和「詞典」用紫色和「自訂」標示，跟著備份和同步。在「轉換」點一個字典裡沒有的詞，也可以直接「加到自訂」。列表裡往右滑 = 加到「不熟」，往左滑 = 收藏。 |
| **⚙︎ 設定**（每個分頁右上角） | 羅馬字、腔口、隱藏意思、自動播放、音量、練習設定、匯出 CSV、備份、匯入。 |

**日語**（設定 → 語言 → 日語）：和其他語言用同一套頁面（新詞、不熟、詞典、熟悉、練習），按鈕是粉紅色。
- 讀音用假名或羅馬字；漢字、平假名、片假名、助詞、語尾各一個顏色（設定 → 顏色與外觀 → 選日語的顏色）。
- **詞典**：用漢字、假名、羅馬字或英文查；變化過的形也找得到（食べなかった → 食べる）；英文意思越接近（剛好是那個詞）排越前面。動詞、形容詞有活用表，詞裡的每個漢字有音讀、訓讀和意思（漢字卡）。
- **助詞**（詞典的方塊）：用法地圖和每個助詞的說明、例句；「練習」裡的「助詞練習」是填空。
- **實驗室**（詞典的方塊，或詞條裡的「在實驗室組合這個詞」）：查一個動詞或形容詞，用滾輪接上語尾（食べ・させ・られ・たく・なかった），每個滾輪都顯示整個詞，下面說明每一部分的作用和整體的意思。

**瑞典語**（設定 → 語言 → 瑞典語，只有 iOS／iPadOS 版）：和其他語言用同一套頁面，按鈕是青綠色。
- 每個詞分成詞素：詞根黃（複合詞的第二個詞根橘）、前綴青、後綴粉紅、連接音（arbet**s**plats 的 s）灰、詞尾紫，詞下面寫成 be-tal-a（設定 → 顏色與外觀 → 選瑞典語的顏色）。
- **詞典**：用瑞典文（變化過的形也可以：bilarna → bil）、英文或中文查。詞條裡有中文和英文解釋、例句（點例句裡的詞可以打開它）、變化（詞尾用詞尾的顏色）、同義詞；「詞的組成」點一個部分，看它的意思和作用（中文和英文說明、例子），和其他有同一個詞根、前綴或後綴的詞。
- 詞典裡沒有的詞會照詞典裡的詞和構詞規則推算：變化（bussarna → buss + arna）、複合詞（varningsområdet = varning + s + område + t）、後綴和詞尾一個接一個（omhändertagandet = omhänderta + -ande 動詞變名詞 + -t 名詞的限定形；每個後綴只接在對的詞類後面），結果會一步一步列出來，在詞典、轉換、例句和 Safari 查詞都一樣。
- 沒有中文解釋的詞（和詞素）可以用 CC-CEDICT 由英文推測中文（照 rime-essay 選常用的詞），標「由英文推測」，在「設定 → 瑞典語」可以關掉。
- 詞素是照規則推算的（前綴、後綴表，和 Folkets lexikon 標的複合詞界線），可能有錯。
- **Safari 查詞**也查瑞典語：用 Pencil 停在一個瑞典文的詞上（或選取它），卡片顯示上色的詞素、每個部分的意思，和中文、英文解釋。

**影片字幕（Safari 查詞，YouTube 和 Viki）**：在 Safari 看 YouTube（或 Viki）的影片時，影片的字幕會出現在旁邊的面板（iPad 橫放和 Mac 在右邊，iPhone 在下面）：正在說的那一行亮起來，前面說過的和後面要說的幾行也看得到，影片播放時整排字幕會平順地往上滑。漢字照華語聲調上色（設定裡的聲調顏色開著的話），有一點光暈。字幕裡的詞和網頁上一樣查：Pencil 或觸控板停在詞上，或用手指點一下；查詞時影片會暫停，卡片關掉後繼續（可以在設定關掉）。按「收藏」或「加到不熟」時，那一行字幕會當作這個詞的例句一起存，「傳到 App」時一起傳過去。點每行前面的時間會跳到那裡；用手指拖（或捲動）可以往前往後看，幾秒後會自己跟回影片。YouTube 上會自己選字幕的語言（台語、繁體中文、粵語、簡體中文、日語、瑞典語的順序，人寫的優先於自動字幕），面板上方可以換，也可以選 YouTube 的「自動翻譯」（翻成繁體中文、簡體中文、日語或瑞典語）；影片沒有這些語言的字幕時，會自己用自動翻譯成繁體中文。影片上原本的字幕預設隱藏（「影片上：開／關」），Safari 工具列的查詞視窗裡，「網頁查詞」和「影片字幕」各有自己的開關：只開影片字幕的話，網頁上停在詞上不會跳出卡片，字幕裡的詞還是點了就查得到。字幕面板上有學習工具：「上一句」「下一句」、「重複」（一直重複這一句）、「慢速」（0.75 倍）、「一句一停」（每句說完就暫停，跟讀用）。在 App 的 設定 → Safari 查詞 按「把認識的詞傳到 Safari 查詞」以後，字幕裡沒學過的詞有虛線、不熟的詞有黃線，面板上顯示「懂 87%」。設定頁的「認識的詞 → 只替不認識的詞上色」打開的話，網頁（聲調顏色選「全部」時）和字幕上認識的詞不上色，只有還沒學的詞有顏色。卡片上多了「認識」：按了馬上算認識，傳到 App 時 App 也會把它標成熟悉。Safari 工具列的小視窗只有兩個開關和要傳的詞，其他都在「所有設定」：一整頁、分成開關、語言、卡片、網頁、影片字幕、認識的詞、傳到 App，藍色是怎麼用、綠色是小技巧、黃色是注意。字幕的大小用面板上的「A−」「A+」調（或在設定裡，從「小」到「最大」八種），和查詞卡片的大小分開。「收起」把面板收成只剩上面一條（「展開」再打開）。「橫排」把字幕改成在畫面下面排成一行，跟著說話的速度一直往旁邊流：正在說的那一行在中間，前後的行在兩邊（「直排」換回來）。在 Mac 和 iPad 上把影片全螢幕時，字幕會自動變成下面那一行，查詞的卡片也看得到。字幕是網站本身的：影片沒有字幕就沒有（YouTube 的自動字幕也可以）。iPhone 上影片全螢幕播放時看不到面板（全螢幕是 iOS 自己的播放器），要在網頁裡看。其他網站的影片，如果播放器的字幕軌 Safari 讀得到，也會出現面板。

**電台**（iPhone／iPad）：上方 ⚙︎ 旁邊的收音機按鈕，一邊練習一邊聽台語、華語、粵語、客語、日語、瑞典語的廣播。每個語言先有幾個常聽的電台；「找電台」可以照語言或名字找更多，也可以貼上串流網址自己加。電台換網址的時候 App 會自己找回來：先用 Radio Browser 的電台 ID 問新的網址，找不到再用名字搜尋，最後才用上次能播的網址。App 在背景、鎖定畫面也繼續播（鎖定畫面可以停止、播放），念詞的發音時電台會自動變小聲。電台有送歌名的話，App 會自己找那首歌的歌詞，顯示在「轉換」的「歌詞」（整頁；電台裡的「歌詞」也會直接打開它）：漢字（開了聲調顏色就上色）和選的拼寫，iPad 和 Mac 上左右並排，iPhone 上拼寫在漢字下面；兩邊的詞都可以按住滑過去放大，點一下就從下面跳出詞典的解釋，可以收藏、加到「不熟」。歌詞不能編輯，也不會改到「轉換」裡的文字。找不到的時候可以自己打歌名。簡體的歌詞會轉成繁體（可以切換）。App 會讀電台送來的所有歌曲資料：一般的網路電台（ICY）、HLS 串流裡的標籤（歌名和歌手分開送的也會合起來），用舊編碼（Big5、GBK、Shift-JIS）送的中文、日文也讀得懂。電台裡的「電台送來的資料」可以看到正在聽的電台到底送了什麼。在歌詞頁存詞或加到不熟的時候，那一行歌詞會跟著詞存起來；電台正在播的話，連最後 15 秒的聲音也存下來（大部分的電台可以，用 HLS 分段送的電台不行）。電台裡有**睡眠定時**（時間到慢慢變小聲再停）和**電台鬧鐘**（時間到從很小聲慢慢變大聲；App 要開著放在背景，被關掉的話會跳出通知）。歌詞頁會顯示你懂這首歌多少（沒學過的詞虛線、不熟的詞黃線）。**練習統計**多了聽電台、看影片字幕的分鐘數、每天存的詞，和一個「學習日曆」。聽到喜歡的歌，按書籤就把歌名和歌手存到「我的歌」（在電台裡），以後可以再看歌詞，或在 Apple Music、YouTube 找。

**捷徑（Shortcuts）**：捷徑 App 裡有兩個方方詞卡的動作。
- **在方方詞卡查詞**：輸入一個詞（華語、台語漢字、羅馬字或方音），打開 App 的「詞典」查這個詞。在那裡可以聽發音、收藏（收藏可以匯出 CSV）、加到「不熟」。
- **方方查詞（小視窗）**（iOS／iPadOS／macOS 26）：在目前的畫面上跳出一張小卡片，顯示最多 4 個結果（漢字、讀音、意思）。卡片上可以 ▶ 聽發音、收藏、加到「不熟」，或按 ↗ 在 App 裡打開，都不用離開你正在用的 App。
- **方方快速查詞**：不打開 App，直接回傳漢字、讀音和意思（文字），可以接到其他捷徑動作。
也可以跟 Siri 說「在方方詞卡查詞」，或把它放到主畫面、動作按鈕、分享選單（搭配「要求輸入」或「從輸入取得文字」）。

**分類詞卡（小工具）**：主畫面長按 → 加入小工具 → 方方詞卡，有 4×2（中）和 4×4（大）兩種。長按小工具 → 編輯小工具，選一個分類（或「常用詞」）。小工具會顯示詞、羅馬字、方音、意思和那個意思的例句（照 App 設定的羅馬字和腔口），每個鐘頭換一個詞，「熟悉」的詞不會出現。按鈕：▶ 聽發音（大的小工具也可以聽例句）、收藏（下次打開 App 時加到收藏）、✓ 標成熟悉（換下一個詞，下次打開 App 時移到「熟悉」）、→ 換下一個詞。第一次要先打開 App 一次，小工具才有詞。（小工具和 App 用 App Group 共用資料，App 的 ID 和 App Group 都由專案設定的 `FF_ID` 決定（App = `FF_ID`，小工具 = `FF_ID.widget`，App Group = `group.FF_ID`），改這一個就好。）

**練習題型**：看意思選台語詞、看台語詞選意思、聽發音選詞、例句填空、看漢字選讀音。連續答對 3 次（可以改）就學會，自動移到「熟悉」。

**聲調練習**（「不熟」分頁）：看漢字、聽發音，從幾個只有聲調不一樣的拼法裡選出正確的。一定會出現容易搞混的那一個（皓羅：1↔8、3↔4；台羅／白話字：1↔4）。答完會顯示每個選項是第幾聲。多音節的詞只換最後一個字的聲調。先用不熟的詞，再用常用詞。

**聲調色球**（「不熟」分頁）：聽一個詞，照每個字的聲調點顏色球（設定裡選的聲調顏色）。每個字都算，不只最後一個；全對有連對加分。台語、華語、粵語、客語（客語只有有錄音的詞）。**例句填空**也會用你自己存詞時的那一句（Safari、影片字幕、歌詞），有電台錄下的聲音的話可以聽。詞的解釋上有**常用度**（五格，越多越常用），和「你看到、聽到的句子」。

右上角的「皓羅」按鈕點一下就換成台羅 → 白話字 → 皓羅。

**唸出來**（「轉換」）：每個結果框右上角的紫色「唸出來」按鈕，會把轉換結果用台羅（通行讀音，按照 App 顯示的讀音和連字號，不送漢字）傳給意傳科技的[鬥拍字](https://suisiann.ithuan.tw/)台語語音合成，唸給你聽。需要網路；長的文章會分句唸。唸過的句子當天會存在手機裡，半暝過後自動清掉。語音是鬥拍字的服務，不包含在這個專案裡，請照鬥拍字的使用方式使用。

**腔口**（每頁上方羅馬字按鈕旁邊，或設定）：通行，或鹿港、三峽、臺北、宜蘭、臺南、高雄、金門、馬公、新竹、臺中。卡片、詞典和例句會顯示那個地方的讀音，方音的 ㄛ／ㄜ 也跟著調整（臺南、高雄一律 ㄜ）。讀音照這個順序決定：

1. 辭典「語音差異」有列那個地方的讀音 → 用辭典的。
2. 選「/」前後哪一個寫法：宜蘭、臺南、高雄、臺中用「/」前面的，其他地方用後面的。
3. 一個音節一個音節看：詞裡面有辭典列過當地讀音的詞 → 用那個；這個字在當地只有一個讀音 → 用那個；有兩個 → 用跟第 2 步一樣的那個；沒有資料 → 照第 2 步的寫法。

**在地詞**（例句）：教育部辭典的「詞彙比較」列了各地對同一個華語詞的講法。選了腔口之後，例句裡的詞如果那個地方另外有講法，會用粉紅色虛線標示；播放鍵上方的「在地詞」開關可以把當地的詞換進句子（粉紅色），「選詞」可以選要用哪一個，或換回原本的詞。為了避免換錯：

- 很常用的詞（在 100 句以上的例句出現，例如 是、真、愛、毋通、啥物、這馬）不會換，也不能選。
- 華語只有一個字的對照（是、很、要、大…）、講法很多的詞（6 種以上）、只是加長或縮短的同一個詞（落雨 → 落雨天）、辭典列為近義詞的（啥物 ↔ 啥貨）：不會自動換，只能自己在「選詞」選。

**華語模式**（每頁上方紫色的「台・…」選單 → 語言，或 設定 → 語言與讀音）：整個 App 換成華語（《兩岸常用詞典》）：新詞、不熟、熟悉、練習（包括聲調練習、排句子、翻牌配對）、詞典和轉換都用華語的詞。華語和台語的進度分開記，但存在同一個進度檔，備份、同步一樣。

- 右上角的按鈕在「拼音」和「注音」之間切換；紫色選單可以選**臺灣**或**大陸**讀音（兩岸讀音不一樣的詞，例如 垃圾 lèsè／lājī）。詞典裡兩種讀音都看得到。
- 聲調顏色：一聲紅、二聲綠（同台語第 5 聲）、三聲藍、四聲紫（同台語第 2 聲）、輕聲灰。
- 卡片是 HSK 3.0 的詞（約 11,000 個），從 HSK 1 開始；「新詞」右上角可以選等級。也可以改用 TOCFL 詞表（設定，或「新詞」右上角的選單）。「熟悉 → 學習進度」顯示每個等級熟悉和不熟的比例，還有「認識的漢字」（熟悉的詞裡的字都算認識，點進去可以看每個字）。詞典有全部 10 萬筆，詞典裡的任何詞都可以加到「不熟」。標「臺灣特有」「大陸特有」的是只在一邊用的詞。
- **漢字卡**：HSK／TOCFL 漢字表的字，加上 3,000 個其他常用字，字義用教育部《重編國語辭典修訂本》。「新詞」右上角的選單選「漢字」的等級。熟悉的詞裡的字，漢字卡會自動標成熟悉。
- 詞典的「單詞比較」華語也有。
- **詞類**：HSK 和 TOCFL 詞表裡的詞有詞類（名詞、動詞、離合詞…），寫法跟台語詞典一樣；點詞類或「依詞類列出」可以看同一類的詞。
- **近義詞、反義詞**：從《重編國語辭典修訂本》來的，詞典裡有的詞才列。
- **英文解釋**一行一個、有藍色編號（卡片上最多 5 個）。設定 → 詞典 →「主要解釋」可以讓卡片和查詞列表先顯示英文。用英文查的時候，常用的詞和第一個意思就是那個字的詞排前面（slow → 慢 在 卡 前面）。
- **手寫練習**（「不熟」）：先選要寫的字（不熟的漢字、HSK／TOCFL 的漢字等級、認識的漢字，或自己打的字；點字可以不選它），再看字、讀音和意思，用手指或 Apple Pencil 在米字格裡寫。右上角「描字」會在格子裡放一個淡淡的楷體字（正體用 Kaiti TC，簡體字用 Kaiti SC；第一次會從 Apple 下載，要網路），藥水條顯示你描得多像（%）。
- 「熟悉 → 學習進度 → 認識的漢字」：按住一個字可以在熟悉和不熟之間換，上面可以找字。
- 「轉換」把華語文字（正體、簡體都可以）轉成拼音和注音。讀音照詞典裡的詞推算，一字多音的地方可能會錯。
- 發音用裝置內建的華語語音（臺灣讀音用臺灣的聲音，大陸讀音用大陸的聲音）。

**部首查字**（詞典 →「部首查字」，台語和華語都有）：「一個部首」：點一個康熙部首，再點你要找的字（照部首以外的筆畫排）。「組合部首」：點好幾個部首（例如 氵 和 毋 → 海），會列出裡面都有這些部首的字（偏旁也算：氵 = 水、亻 = 人、艹 = 艸…），不可能再組合的部首會變淡。點字會放進搜尋框。

**一次查好幾個詞**：打「陰謀論」這種詞典沒有的詞，會自動拆成詞典有的詞（陰謀、論），也可以自己用空格分開（陰謀 論）。台語詞典上方會有每個詞的按鈕，點一個（會變成它的顏色）就看那個詞的「更多」（詞裡有、解釋裡有、華語意思有…）。

**日語借詞**（台語詞典）：辭典說是從日語來的詞，跟日語原本的寫法。

**常用詞分組**（台語）：台語的詞照常用的程度每 500 個一組（常用詞 1–500…），單一個字另外分「常用字」。「新詞」右上角可以選一組來滑，「熟悉 → 學習進度」看每一組的進度。

**練習範圍**（「不熟」）：只練一個等級（華語 HSK／TOCFL 的詞或漢字）或一組（台語常用詞／常用字）的不熟的詞；下面的列表也只列那些詞。

**練習做到一半**：關掉練習（或 App）再打開，會接著上次的題目做（每種練習各記一個，台語華語分開，兩個星期以後就不記了）。右上角的 ↺ 可以重新開始。

**在 App 裡安裝詞典**：設定 → 詞典資料。詞典的授權不允許分享改過的版本，所以 App 從原本發布的地方下載檔案，在 iPhone／iPad 上自己整理（`FangfangCards/Install/*.js`，用 JavaScriptCore 跑，和 tools/ 裡的 Python 做出一樣的資料）。台語、華語（含倉頡、五筆碼）、粵語、客語、日語、瑞典語和說文解字都在 App 裡安裝。粵語在手機上不用維基詞典（2.5 GB 太大）：詞、粵拼、英文解釋和漢字都有，沒有維基詞典的例句、錄音和華語對照；台語詞的英文和四川話讀音也是維基詞典的，所以只有 `install.sh` 在 Mac 上建立的資料裡有（給 Safari 查詞用）；其中四川話讀音（`zh_sc.json`）和台語詞的英文（`tw_en.json`，台語的英文查詞要用）會放進 App，是 App 裡唯二的資料。電腦上也可以跑：`node tools/convert.js taigi|mandarin|inputcodes|hakka|cantonese|japanese …`（參數見檔案開頭）。安裝的檔案在 App 的 Application Support/Dictionaries 裡。

**Safari 查詞（iPad／iPhone）**：在 Safari 用 Apple Pencil 停在一個中文字上面（不碰到螢幕），會跳出從那個字開始的華語詞和台語詞。沒有懸停功能的 iPad 用手指選取詞，觸控板的游標也可以。卡片右上角的「設定」選拼寫、腔口、聲調顏色和要顯示的語言；「加到不熟」「收藏」選好詞以後，按「傳到 App」會打開方方詞卡把詞加進來。開啟：設定 → App → Safari → 延伸功能 → 方方詞卡 查詞，允許「所有網站」。查詞的詞是 `install.sh` 在你的 Mac 上從詞典資料做的，放在延伸功能裡（`FangfangSafari/d-*.json`，不在這個專案裡），所以不需要 App Group，用 Sideloadly 裝也可以用。（延伸功能的 ID 是 `FF_ID.safari`。）

**小工具**：除了台語的分類，也可以選「不熟的詞（台語）」「不熟的詞（華語）」或華語的每個等級和漢字等級；編輯小工具時打開「只顯示不熟的詞」就只出現你往左滑過的詞。

**複製意思的格式**（設定 → 詞典）：台語和華語各有一個；華語可以加 {英文}、{英文列表}、{詞類}、{簡體}。

**卡片先隱藏讀音**（設定 → 卡片與練習）：跟「先隱藏意思」一樣，點一下卡片才看得到。

**主題動畫**（設定 → 顏色與外觀）：關掉的話背景和藥水條都不動，比較省電。

**匯入備份**的時候會有一條彩色藥水條顯示進度。兩個詞典在 App 打開的時候就在背景載入，切換華語不用等。

**選聲調顏色**（設定 → 顏色與外觀）：台語和華語每個聲調都可以換顏色，從一排排的顏色球裡選（每種顏色由淺到深）。

**外觀主題**：方方之夜、女巫小屋、星空、苔蘚小窩、雪夜。App 打開時在「詞典」。

**主題**（「新詞」左上角）：照教育部辭典的分類滑卡片，例如「食物、飲料、煙酒」「稱謂輩分」「時間節令」。

詳細頁也會顯示其他讀音（又／俗／合）、近義詞、反義詞和分類。

## 腔口讀音：歡迎指正 🙏

選了腔口（鹿港、三峽、臺北、宜蘭、臺南、高雄、金門、馬公、新竹、臺中）之後顯示的讀音，**很多是推算出來的，不一定正確**：

- 教育部辭典的「語音差異」只列了約 400 個常用字詞在各地的讀音。這些是辭典的資料。
- 其他的詞（例如複合詞「白飯」「轉去」），是把單字的腔口讀音帶入用同一個讀音的詞推算的；例句裡的詞也是這樣換的。
- 推算的讀音在 App 裡用**紅色**和「推測」標示；換成當地講法的詞是**粉紅色**。

有些推算一定會錯，例如一個字在某些詞裡保留不同的唸法、文讀和白讀拼法相同、或是一個地方本身就有兩種講法。

**如果你是這些地方的人，或很熟悉當地的腔口**，非常歡迎告訴我們哪裡唸得不對、當地實際怎麼講。請到 [Issues](../../issues) 開一則，寫上：地方、詞（漢字）、App 顯示的讀音、當地的讀音（台羅或皓羅都可以），有例句更好。每一則回饋都很珍貴，謝謝！

*Local readings: many of the readings shown for a chosen place are **educated guesses** (shown in red in the app), worked out from the ~400 words the MOE dictionary lists per place. If you are a native speaker of one of these varieties, corrections and comments are very welcome and much appreciated — please open an [issue](../../issues) with the place, the word, what the app shows and how it's said locally.*

## 進度與備份

- 進度存在 App 裡面。重新安裝（執行 install.sh）不會清掉進度；把 App 刪掉才會。
- **自動備份**：設定 → 自動備份 → 選擇備份資料夾（建議 iCloud Drive 裡開一個「方方詞卡」資料夾）。之後每次打開和離開 App 都會自動備份，每天另存一份到「方方詞卡舊備份」（保留 14 天）。
- **iPhone ↔ iPad 同步**：兩台都選同一個資料夾。每台寫自己的備份檔，打開 App 時會讀另一台的檔案，同一個詞以比較新的變更為準。
- **手動備份**：設定 → 備份檔分享／另存，在另一台裝置 **匯入備份**。
- **匯入方方收藏**：選方方網站或 Safari 擴充功能匯出的備份檔，收藏的詞會加到「不熟」。
- **匯出 CSV**：跟方方網站的收藏 CSV 一樣（分號分隔，九欄），可以匯入 Anki。

- **匯出到 Anki**（設定 → 匯出與匯入）：一個 Anki 可以直接匯入的檔案，正面是詞，背面是讀音、意思和例句（自己存的句子優先），放進「方方詞卡::語言」牌組，標籤「不熟」或「熟悉」。
